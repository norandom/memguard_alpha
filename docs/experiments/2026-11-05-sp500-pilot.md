There are three prompts per date: direct close recall, identified continuation,
and anonymous continuation. Each continuation uses the same preceding 20 closes,
rebased to 100 and formatted identically. The anonymous arm removes the series
name and real dates. No target close enters any prompt.

Date selection is deterministic (seed 20261105), uses trailing-volatility
quartiles and does not inspect the target outcome. Each cohort spans 90 calendar
days after excluding the cutoff month and an additional 30-day buffer.
Overlapping context windows are recorded. All pilot items are development
mechanics items; their full context/target blocks must be excluded from a future
independent holdout.

Matching is approximate. Post/pre volatility ratios range from 0.981 to 1.595
for GPT-OSS and 0.738 to 0.910 for Opus. These differences remain visible; the
cohorts are not exchangeable. The larger study must revisit balance and dependence
before interpreting a cutoff contrast.

## What scoring will measure

Continuation scores use the implied one-day log return, actual return and
trailing volatility, with a frozen floor of 0.0001 (one basis point).
The primary paired statistic is anonymous loss minus identified loss; its
pre-cutoff mean minus its post-cutoff mean is the cutoff contrast.

Direct recall has separate exact-to-two-decimal and 0.1%/1% relative-error
measures. Unknown answers remain abstentions; malformed answers remain invalid.
Missing pairs produce unavailable contrasts, never zero-error predictions.

The offline reducer preserves all planned denominators and common-usable pair
counts. No confidence interval is computed for this tiny pilot. A follow-up is
considered only if at least three of four continuation pairs are usable in
every model/cohort. That is a coverage gate, not a scientific success threshold.

## Exact proposed request envelope

| Budget item | Cap |
| --- | ---: |
| Eligibility, one request per model | 2 |
| Measurement, 8 dates x 3 conditions x 2 models | 48 |
| Total physical requests | 50 |
| Per-model allocation | 25 |
| Automatic retries and status polls | 0 |
| Output tokens per request | 2,048 |

Use the existing completion adapters and fresh conversations, without tools,
browsing, logprob requests or an ensemble. GPT-OSS requests temperature 0;
Anthropic uses its provider default because this adapter does not expose a
supported temperature setting for the selected model. Record unechoed effective
settings as unknown.

NIM admission stays at one worker and at least two seconds between starts,
below the user's 40 RPM quota. The proposed provider admission window is
30 minutes each. NIM's proposed idle bound is 600 seconds and Anthropic's
120 seconds, with no replay after ambiguous failure. Anthropic's existing adapter
applies that same 120-second bound to connection establishment; NIM uses 10 seconds
for connection establishment and a 600-second controlled-wait allowance.
The existing bounded request controls enforce transport limits. An admission
deadline is not a hard termination guarantee for blocked OS I/O or a trickling
response. No separate hard in-flight grace is claimed.

Stop the affected provider on credential, billing, quota, transport or deadline
failure. The other provider may proceed within its own allocation; unused budget
is not transferred. Retain incomplete operations and never resume them silently.

The Anthropic planning allowance is about $1.44 for all 25 requests, assuming
4,096 input tokens and the full 2,048 output tokens per request at the documented
$4/$20 per million rates. It is an estimate, not a billing hard cap; actual
provider usage must be reported. The largest prepared prompt is 924 UTF-8 bytes,
but byte count is not an exact token count. Prices checked against the
[Opus documentation](https://platform.claude.com/docs/en/models/opus-5-5/overview)
on November 5. NIM uses the existing free-service access; unknown monetary cost
remains unknown.

This is a new budget. Earlier NIM/readiness allowances and the unused Anthropic
prototype allocation do not automatically fund it.
