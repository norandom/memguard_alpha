FRED SP500 is the proposed source; it has ten years of daily history and S&P
redistribution restrictions. Do not confuse it with SPY, adjusted ETF prices or

permitted. Preserve source URL, retrieval timestamp, series identity and hash.

Freeze candidate trading dates around each model's own cutoff, applying the
proposal's exclusion buffer and pre/post matching. Keep missing/nontrading days
explicit; no forward-filled weekend pseudo-observations. Recheck the latest
available completed observation rather than assuming today's data is present.

Create three conditions per date:
- Direct historical close recall from index identity and date.
- One-day continuation from the prior 20 closes, dates and index identity.
- The same continuation using identical rebased numeric inputs but no real dates
  or index identity.

Both continuation arms use the same scale and formatting. No target close or
future values enter the prompt. No browsing or tools in target requests.
Score implied daily returns, normalized errors against actual returns, and the
paired advantage from revealing identity. Compare that advantage pre/post cutoff.
Use unchanged-close as the baseline. Raw price variance or price correlation is
not the primary measure. Repeated identical prompts are not a substitute for
distinct dated observations.

Prepare offline parser/scoring tests and the exact pilot manifest and budget.

## Reliable Docker invocation

Use long options: PowerShell's docker wrapper can misinterpret short flags.
Quote comma-separated mount arguments. Do not use --env-file .env because quoted
dotenv values can become literal quotes. Explicit read-only credential-file mount
plus dotenv parsing is the established pattern when a live run is authorized.

Example offline command:

    docker run --rm --network none --mount 'type=bind,source=/mnt/d/Source/memguard_alpha,target=/app,readonly' --workdir /app --env UV_PROJECT_ENVIRONMENT=/opt/venv recall-guard:dev uv run --no-sync pytest tests/scripts/test_temporal_signature.py tests/experiments/test_divergence_trigram.py -q --override-ini cache_dir=/tmp/pytest-cache
    exit $LASTEXITCODE
