## Implementation Notes

- Validation route (user decision 2026-11-09): tests, ruff and the architecture check run natively from PowerShell with `uv run --no-sync pytest -q <paths>`, `uv run --no-sync ruff check .` and `uv run --no-sync python scripts/check_architecture.py` (lint plus architecture check take about 1 s). Containers run natively through Podman Desktop since 2026-11-10. User decision: Compose for runs (study scripts, the runner, anything touching data or hosts: `docker compose run --rm dev uv run --no-sync ...`), native uv for the unit-test loop, `dagger -m ci call ...` as the CI gate; WSL is no longer used.
